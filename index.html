TextForge
paste · transform · copy

An all-in-one text toolkit for sysadmins, developers and writers. Paste text, pick a transform, copy the result — all without leaving your browser tab.

  • Clean spaces, strip HTML, remove accents
  • UPPERCASE / lowercase / Title Case / Sentence case
  • Sort, deduplicate and number lines
